# AI-Powered Educational ERP System

A simple educational ERP dashboard with student, attendance, fees, results and AI performance prediction modules.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Modules
- Student Management
- Attendance Management
- Fees Management
- Result Management
- AI Student Performance Prediction
